
# AppSocola

## Giới thiệu
AppSocola là ứng dụng thương mại điện tử bán socola,
được xây dựng phục vụ đồ án môn Lập trình Front-End.

## Công nghệ sử dụng
- ReactJS
- Vite
- JavaScript
- HTML, CSS
- Fake REST API

## Yêu cầu môi trường
- Node.js
- npm

## Cài đặt dự án

Clone repository:
git clone https://github.com/PhamVanViet23130380/AppSocola.git

Di chuyển vào thư mục:
cd AppSocola

Cài đặt thư viện:
npm install

Khởi chạy ứng dụng:
npm run dev

## Chức năng dự kiến
- Hiển thị danh sách sản phẩm socola
- Xem chi tiết sản phẩm
- Tìm kiếm và lọc sản phẩm
- Quản lý giỏ hàng
- Đặt hàng
- Quản lý sản phẩm
